# Welcome to Specmatic 👋

## Shift-left API Integration
### Auto-fix integration drift before integration

[Specmatic](https://specmatic.io) turns API specifications into **executable contracts**, continuously verifying that every change made by AI coding agents and engineers stays true to the intended behaviour.

**Ship AI-ready APIs 10x faster, from intent to implementation, with Spec-Driven API Development.**

Design, validate, test and govern high-quality APIs at scale. Specmatic brings the entire API development lifecycle together around the same API specifications, transforming **OpenAPI/Swagger, Arazzo, AsyncAPI, GraphQL, gRPC and WSDL** into executable contracts.

## 🚀 The Specmatic Platform

**One set of API specifications. An entire lifecycle of development, testing and governance.**

| Product | What It Does |
|---|---|
| ✍️ **Scribe** | **AI-native API Designer** – Go from idea to high-quality, AI-ready API specifications. |
| 🔍 **Skeptic** | **API Linter** – Validate API specifications and examples to catch design issues early. |
| 🧪 **Studio** | **Visual Contract Testing & Mocking** – Design, execute and explore contract tests and service virtualisation without writing code. |
| ⚙️ **Core** | **Developer CLI & Libraries** – Automate contract testing, service virtualisation and specification-driven testing in local development and CI/CD. |
| 📊 **Insights** | **Continuous API Governance** – Gain visibility into API quality, compatibility and compliance across your API ecosystem. |
| 🤖 **Genie** | **AI Agent Harness** – Enable AI coding agents to design, implement, test and evolve APIs while continuously verifying alignment with specifications. |

### 🔧 What Can You Build with Specmatic?

- **Contract Testing:** Verify that API implementations conform to their specifications.
- **Service Virtualisation:** Generate realistic mocks from API specifications to develop and test services independently.
- **Dynamic Test Generation:** Automatically generate tests, including boundary and negative scenarios, from API specifications.
- **Backward Compatibility Testing:** Detect breaking API changes before they affect consumers.
- **Async Contract Testing:** Validate event-driven interactions involving Kafka, MQTT, SNS/SQS, RabbitMQ, ActiveMQ and other messaging systems.
- **Workflow Testing:** Validate multi-step API interactions and business workflows using Arazzo specifications.
- **AI-Assisted Development:** Keep AI-generated implementations aligned with API specifications through continuous verification.
- **Continuous Governance:** Track API quality, compatibility and specification coverage across teams and repositories.
